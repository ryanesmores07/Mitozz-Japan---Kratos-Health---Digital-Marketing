# Mitozz Posting Copy Optimizer

Use this skill after the asset direction is approved and before the asset is treated as fully production-ready, delivered, or scheduled.

This skill is focused only on posting copy for the approved asset on that date.

It does not redesign the visual.
It does not rewrite the concept.
It turns the approved asset into ready-to-publish posting language.

Every caption and hashtag set must stay traceable to one exact approved asset lineage.
If the approved creative package version, rendered output basename, or final exported asset changed, re-check the copy before publishing instead of assuming the previous caption still fits.

If the completed work materially advances production readiness or closes a workflow gap, add a concise entry to the current monthly retainer action log under `brand/references/business-context/reporting/monthly-action-logs/`.

## Role

This skill owns:

- `caption_ja`
- `hashtag_set`
- optional `first_comment_ja`
- posting notes tied to the approved asset
- posting-copy pack maintenance
- discovery notes when current-platform research materially affects the recommendation

This skill does not own:

- the core message angle
- the visual concept
- on-canvas copy changes

Those stay with `mitozz-creatives-director`.

If trend research would materially change the post angle, format, or timing, route that decision through `mitozz-instagram-strategist` before finalizing copy.

## Operating Stance

Optimize in this order:

1. audience fit
2. caption clarity
3. saves, shares, and trust
4. search relevance
5. hashtag precision

Treat hashtags as precise classifiers, not as a growth hack.

Do not promise the "best" audience, engagement, or traction as if it can be guaranteed.
Maximize fit from verified current information, internal account context, and the approved asset.

## Current-Platform Research Mode

Enter current-platform research mode when any of the following is true:

- the user asks for the latest, best, current, trending, or growth-optimized hashtags
- the user asks for stronger search or keyword optimization
- the user asks for better audience fit, engagement, or traction
- the post depends on current seasonal language, trend framing, or topic adjacency

When this mode is active, verify current platform-sensitive guidance before making claims about hashtag or discovery behavior.

Use this source order:

1. official Instagram or Meta creator/business guidance
2. recent public statements from Instagram leadership
3. recent trustworthy reporting when official guidance is incomplete
4. latest internal Mitozz metrics snapshots and approved-post history
5. recent relevant Japan-facing phrasing or seasonal conversation only when it materially improves wording

Rules:

- use exact dates when current guidance materially changes the recommendation
- if live verification is not possible, say the output is relevance-optimized but not live-trend-verified
- do not invent search volume, competition scores, or "viral" confidence
- do not use trend language that weakens premium brand fit

## Japanese Market Hashtag Norm

Default to Japanese corporate-organic hashtag behavior, not creator-style hashtag stuffing.

Use this norm unless verified current platform guidance or the user explicitly calls for something else:

- keep the set short
- lead with brand relevance
- prefer Japanese wording over English filler
- use 1 brand tag plus 2-4 highly specific topic, selection-intent, or context tags
- make the tags read like the language a careful Japanese buyer or brand account would actually use

Reference behavior:

- Japanese large-brand Instagram campaigns and corporate-organic posts commonly use a small set of tightly scoped hashtags instead of broad generic stacks
- treat that as the default Mitozz posture for trust-oriented feed posts
- avoid imported creator tactics that feel noisy, salesy, or trend-first in the Japan premium-wellness context

## Caption Rules

Write in natural Japanese that feels:

- premium
- calm
- specific
- easy to read in Instagram
- compliant for Japan general-food-safe communication

Do:

- align tightly with the approved post angle
- front-load the main searchable topic words naturally in the opening lines
- preserve the same reading lens as the visual asset
- use audience phrasing supported by current research when current-platform research mode is active
- aim for saves, trust, clarity, and repeat familiarity before hard conversion
- end with a soft CTA that matches the post goal

Do not:

- invent a new angle
- add medical or guaranteed-result claims
- write like a noisy supplement ad
- overstuff the caption with keywords
- let hashtags carry the meaning instead of the caption
- write for a hashtag block instead of a real person

## Discovery System

Treat "SEO" here as Instagram discovery and search optimization, not web SEO.

Optimize in this order:

1. semantic alignment between the asset, cover, and caption
2. caption opening line and primary keyword phrasing
3. audience-intent language
4. save and share value
5. tightly matched hashtags
6. supporting first comment only when it adds clarity

Do not let hashtags do work that should belong to the creative, caption, or CTA.

## Keyword Research Method

1. Identify the exact approved asset, date, persona, and CTA.
   - record the exact creative package filename
   - record the exact approved output basename or delivered asset path
2. Extract the locked keyword cluster from the creative package:
   - brand
   - primary topic
   - audience problem or question
   - routine or use-case context
   - compliant outcome lens
3. When current-platform research mode is active, verify current adjacent language using:
   - official Instagram or Meta guidance
   - recent leadership statements
   - recent search or news results for the topic and Japan-facing phrasing
   - latest internal metrics and approved-post history
4. Build a candidate keyword pool using only phrases that genuinely fit the asset.
5. Rank candidates by:
   1. brand fit
   2. audience-intent match
   3. search clarity
   4. specificity
   5. current relevance or seasonality
   6. anti-spam quality
6. Choose one primary keyword theme and no more than two secondary themes.
7. Write the caption with the primary theme early and the secondary language distributed naturally.
8. Select `3-5` hashtags from that same theme set.

## Hashtag Rules

Default to `3-5` highly relevant hashtags only.

If verified current platform guidance becomes stricter, follow that guidance.

Weight them toward:

1. brand
2. core topic
3. user intent
4. asset context or seasonality

Good mix:

- one brand tag
- one core-topic tag
- one supporting concept tag
- one user-intent or audience-lens tag
- one seasonal or context tag only when it is real and current

For Japan-facing Mitozz posts, prefer tags that resemble disciplined corporate-brand usage such as:

- brand
- category or topic
- selection lens
- trust or quality lens
- routine or context lens

Prefer:

- specific Japanese phrases the target audience might actually search or recognize
- tags that reinforce the caption's main nouns
- tags that narrow audience fit rather than inflate tag volume

Avoid:

- large generic discovery stacks
- spammy trend tags
- English filler tags unless the asset genuinely needs them
- weak tags that do not match the caption or creative package
- tags chosen only because they look popular
- generic health or wellness tags that do not add audience precision
- claiming a tag is "best" without current evidence

## Hashtag Decision Check

Before finalizing, ask:

1. Does each hashtag help the right viewer self-identify?
2. Is it semantically aligned with the asset, caption, and cover?
3. Is it specific enough to signal intent without becoming obscure?
4. Is it current and culturally relevant if it uses a seasonal or trend phrase?
5. Would this still be a good tag if reach stayed flat but audience fit improved?
6. Would this tag still look credible if it appeared on a careful Japanese corporate account?

If the answer is no, replace it.

## Workflow

1. identify the exact approved asset and date
2. read the creative package, exact output lineage, and the calendar row
3. extract the locked message angle, CTA, persona, and keyword cluster
4. enter current-platform research mode when latest, best, current, trending, or traction optimization is requested or materially useful
5. write the caption from the approved angle using the strongest audience-fit keyword phrasing
6. generate a short relevance-weighted hashtag set using Japanese market corporate-brand norms by default
7. add a discovery note when live verification influenced the choice
8. update the active posting-copy pack if one exists for that date window
9. if no pack exists, create one in `brand/references/business-context/creative-packages/`
10. do not mark the asset fully production-ready until this is done

## Coordination Rules

- `mitozz-creatives-director` decides the message angle and CTA direction
- `mitozz-posting-copy-optimizer` turns that angle into publish-ready caption language and hashtag logic
- `mitozz-instagram-strategist` should be consulted first if live trend research suggests the topic, timing, or format should change
- `mitozz-compositor-executor` should not be the one improvising caption language
- if the user asks for the freshest platform-sensitive recommendation, verify it before finalizing the answer
