# Canva Carousel Master Library

## Purpose

This file defines the first `45` Canva master templates for Mitozz Japan Instagram carousel production.

These are reusable master layouts, not one-off posts.
Each one should be built once in Canva, saved under `01 Carousel Masters`, and duplicated into `02 Working Drafts` when a live post needs it.

## Core Rules

- Build every master at `1080 x 1350`.
- Stay inside the `Steel Light` visual world.
- Use `Set 1 + Set 2` as the default carousel logic.
- Keep one clear idea per slide.
- Let white space carry brand value.
- Use apricot as a signal, not a dominant field.
- Keep dense Japanese copy in the sans lane.
- Keep product, portrait, and lifestyle slides calm and premium.

## Set 1
